# My Portfolio
I made this portfolio to showcase my work and all important links and such <3

Do let me know if you have any suggestions on this :D
## Tech Stack

- **Core & Framework**: React 19, TypeScript
- **Build Tool**: Vite
- **Styling**: Vanilla CSS
- **Audio Engine**: Web Audio API 
- **Graphics & Visuals**: HTML5 Canvas (Particle physics engine)
- **Browser APIs**: Clipboard API, Canvas 2D API, Web Audio API

## Requirements

- Node.js 20+
- npm

## Run Locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Production Build

```powershell
npm.cmd run build
npm.cmd run preview
```
